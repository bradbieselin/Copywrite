# Content Repurposing Prompt

> **Purpose:** Claude prompt that takes one piece of content and transforms it into multiple formats for different platforms. Maximizes the value of every content idea.
> **Status:** Scaffold — full content to be built in subsequent prompts
> **Used by:** Brad when a piece of content performs well and should be repurposed across channels

## Contents

### The Prompt
- Input: the original content piece (blog post, thread, LinkedIn post, video transcript, etc.)
- Input: which platforms to repurpose for
- Input: any performance data from the original (what resonated most)

### Output Options
- Blog post → Twitter thread → LinkedIn post → Instagram carousel → TikTok script → newsletter section → email content
- Thread → blog post (expanded) → LinkedIn post (condensed) → Instagram carousel
- LinkedIn post → tweet series → Instagram caption → email snippet
- Video/podcast → blog post → social quotes → audiogram scripts

### Repurposing Rules
- Each version should feel native to its platform (not just copy-pasted)
- Adjust length, tone, and format for each channel
- Preserve the core insight but change the delivery
- Add platform-specific elements (hashtags for Instagram, hooks for TikTok, etc.)
- Note which platforms the content is best suited for (not everything works everywhere)

### Quality Bar
- Repurposed content should feel fresh, not recycled
- Each version should stand alone (someone who saw the original shouldn't feel bored)
- Platform-specific best practices followed for each output

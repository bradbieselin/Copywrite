# Audit Report Template

> **Purpose:** Formatted template for presenting content audits to prospects. Professional layout that makes the audit feel premium and positions CopyDTC as experts.
> **Status:** Scaffold — full content to be built in subsequent prompts
> **Used by:** Brad when formatting audit output into a client-facing document

## Contents

### Report Layout
- Cover page: CopyDTC logo + "Content Audit for [BRAND_NAME]" + date + "Prepared by Brad Bieselin, CopyDTC"
- Table of contents
- Executive summary (1 page)
- Channel audits (1-2 pages)
- Competitive analysis (half page)
- Recommendations (1 page)
- About CopyDTC + next steps (half page)

### Design Notes
- Clean, professional formatting
- Use brand colors where possible (shows we pay attention)
- Include screenshots of their actual content with annotations
- Charts for competitive comparison where applicable

### Delivery
- Format: PDF (exported from Google Docs or Notion)
- Delivery email: see email-templates.md #5
- Follow-up: schedule call 2-3 days after sending to walk through findings

### Conversion Strategy
- The audit should naturally surface problems that our services solve
- Never hard-sell in the audit — let the quality of the analysis do the selling
- End with "If you'd like to discuss these findings and how we can help implement them, I'd love to set up a 30-minute call."

# Master Generator Prompt

> **Purpose:** The universal content generation prompt for CopyDTC. When no specific template exists for a deliverable type, this master prompt can generate any type of DTC content by combining a client's Brand Voice Bible with a flexible content specification.
> **Status:** Scaffold — full content to be built in subsequent prompts
> **Used by:** Brad when producing content that doesn't have a dedicated template, or when a client needs something custom

## Contents

### The Prompt
- Input: client's Brand Voice Bible (full or Quick Reference Card section)
- Input: content type specification (what to produce)
- Input: content details (topic, goal, audience, length, format, channel)
- Input: any reference material (examples, competitor content, previous versions)

### How It Works
The master generator is a flexible meta-prompt that:
1. Absorbs the brand voice from the Bible
2. Understands the content type and its platform-specific requirements
3. Applies DTC copywriting best practices for that content type
4. Produces output in the appropriate format with quality checks

### Content Types Supported
- Any email type not covered by specific templates
- Website microcopy (navigation, error messages, pop-ups, etc.)
- Packaging copy
- Direct mail copy
- Video scripts (beyond TikTok — YouTube, brand videos, etc.)
- Podcast show notes and descriptions
- Event copy (webinar invites, event pages, etc.)
- Partnership and co-marketing copy
- PR pitches and media kit copy
- Internal communications for the client's team

### Output Format
- Adapts to the content type automatically
- Includes: the content itself, strategic notes, format specifications, and quality checks
- Always ends with "Quality Checks Before Sending" relevant to the content type

### When to Use This vs Specific Templates
- Use specific templates when they exist (they're more optimized)
- Use this master prompt for one-off or unusual content requests
- Use this when a client needs something we haven't built a template for yet
- If you use this prompt more than 3x for the same content type, build a dedicated template

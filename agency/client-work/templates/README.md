# CopyDTC Prompt Templates Index

> Every template in this directory is a production-ready prompt designed to be pasted into Claude along with a client's Brand Voice Bible variables. Each one produces a specific deliverable type for DTC ecommerce brands.

## How to Use These Templates

1. Open the template for the deliverable type you need
2. Copy the **Client Brand Variables** section and fill in values from the client's Brand Voice Bible
3. Paste the completed variables + the prompt into Claude
4. Review the output against the **Quality Checks Before Sending** section
5. Deliver to client

Every template includes a complete example output using a fictional DTC brand so you can see the quality bar before generating content.

## Template Structure

Every template follows this consistent structure:

1. **Quick Reference** — what it produces, turnaround time, quality bar, best for
2. **Client Brand Variables** — standard variable block to fill from Brand Voice Bible
3. **The Prompt** — the actual prompt to paste into Claude
4. **Output Format** — exact format specs with word/character counts
5. **Quality Checks Before Sending** — 5-7 verification items
6. **Example Output** — complete production-quality example

## Adding New Templates

When creating a new template, follow the same structure above and add it to this index. If you use a template type more than 3x that doesn't have a dedicated file, build one.

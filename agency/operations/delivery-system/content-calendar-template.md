# Content Calendar Template

> **Purpose:** Monthly content planning document used to map out all deliverables for a client, organized by week with deadlines, status tracking, and strategic notes.
> **Status:** Scaffold — full content to be built in subsequent prompts
> **Used by:** Brad (and future project managers) at the start of each month to plan and track all client deliverables

## Contents

### Calendar Structure
- Month/Year header with client name and tier
- Weekly breakdown (Weeks 1-4)
- Daily slots for content types: Email, Blog, Social, Ads, Landing Pages, Product Descriptions, SMS

### Per-Deliverable Fields
- Content type
- Specific deliverable (e.g., "Welcome Sequence Email 3")
- Template used (link to template file)
- Draft deadline
- Review deadline
- Delivery deadline
- Status: Not Started / In Progress / In Review / Approved / Delivered
- Notes / Strategic context

### Monthly Overview Section
- Total deliverables planned by type
- Key campaigns or launches this month
- Client priorities and goals
- Holidays or events to plan around

### Tier-Based Volume Guide
- Starter ($3K): ~15-20 deliverables/month
- Growth ($5K): ~25-35 deliverables/month
- Scale ($10K): ~50-70 deliverables/month

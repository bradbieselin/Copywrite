# Weekly Review Template

> **Purpose:** Framework for Brad's weekly business review. A 30-minute Friday ritual to assess what happened this week, what's coming next week, and what needs attention.
> **Status:** Scaffold — full content to be built in subsequent prompts
> **Used by:** Brad every Friday afternoon

## Contents

### This Week's Numbers
- Revenue collected this week: $___
- New leads generated: ___
- Proposals sent: ___
- Clients onboarded: ___
- Deliverables produced: ___
- Deliverables delivered: ___

### Client Health Check
For each active client:
- Status: Green (happy) / Yellow (needs attention) / Red (at risk)
- Deliverables on track? Y/N
- Any outstanding feedback or revisions?
- Upcoming deadlines or milestones

### Sales Pipeline Review
- New prospects added this week
- Outreach sent and response rates
- Audits/proposals in progress
- Expected closes next week

### What Went Well
- Top 3 wins this week (client wins, operational improvements, personal growth)

### What Needs Improvement
- Top 3 issues to address (process gaps, client concerns, capacity issues)

### Next Week's Priorities
- P1 (must do): ___
- P2 (should do): ___
- P3 (nice to do): ___

### Action Items
- [ ] Action 1 — Owner: ___ — Due: ___
- [ ] Action 2 — Owner: ___ — Due: ___
- [ ] Action 3 — Owner: ___ — Due: ___

# Client Folder Template

Duplicate this folder for each new client. Rename the root folder to the client's name.

## How to Use

1. Copy this entire `client-folder-template` directory.
2. Rename the copy to the client's brand name (e.g., `Hydrant`, `Ridge Wallet`, `OLIPOP`).
3. Move the renamed folder into `/clients/` in the main CopyDTC drive.
4. Add the Brand Voice Bible to `/brand-guide` as soon as it's completed.
5. Begin organizing deliverables into the appropriate subfolders from Day 1.

## Structure

```
[CLIENT NAME]/
|
|-- /brand-guide
|   Brand Voice Bible and any supplementary brand assets.
|   Includes the completed client questionnaire, Brand Voice Bible PDF,
|   brand guidelines provided by the client (logos, color codes, fonts),
|   and any mood boards or reference materials.
|
|-- /content-calendar
|   Monthly content calendars organized by month.
|   Each month gets its own file (e.g., 2026-03-content-calendar.xlsx).
|   Includes all deliverable types, deadlines, and status tracking.
|
|-- /deliverables
|   All produced content, organized by type.
|
|   |-- /emails
|   |   Welcome sequences, abandoned cart flows, post-purchase flows,
|   |   browse abandonment, winback sequences, sunset flows,
|   |   promotional campaigns, product launch emails, and newsletters.
|   |   Name files clearly: welcome-flow-email-1.md, abandoned-cart-email-2.md, etc.
|   |
|   |-- /landing-pages
|   |   Product pages, collection pages, advertorials, squeeze pages,
|   |   and any long-form sales page copy.
|   |   Name files by page type and product: pdp-hero-serum.md, collection-skincare.md, etc.
|   |
|   |-- /blog-posts
|   |   SEO content, listicles, how-tos, gift guides, comparison posts,
|   |   and any long-form educational content.
|   |   Name files by topic: best-morning-routine-for-dry-skin.md, etc.
|   |
|   |-- /social
|   |   Instagram captions, TikTok scripts, Twitter/X posts, and Pinterest descriptions.
|   |   Organize by platform and month: ig-march-2026.md, tiktok-scripts-march-2026.md, etc.
|   |
|   |-- /ads
|   |   Meta (Facebook/Instagram) ad copy, Google Ads copy, TikTok ad scripts,
|   |   and any other paid media copy.
|   |   Organize by platform and campaign: meta-spring-sale-2026.md, google-search-brand.md, etc.
|   |
|   |-- /product-descriptions
|   |   Product page copy for individual SKUs.
|   |   Name files by product: hero-vitamin-c-serum.md, recovery-protein-bar.md, etc.
|   |
|   |-- /sms
|       SMS marketing messages, flows, and campaigns.
|       Organize by type: sms-welcome-flow.md, sms-promo-march-2026.md, etc.
|
|-- /feedback
|   Client feedback on deliverables, organized by date.
|   Store revision requests, approval notes, and any recorded feedback here.
|   Name files by date and batch: feedback-2026-03-05-batch-1.md, etc.
|
|-- /reports
    Monthly performance reports and analytics summaries.
    Each month gets its own report: report-2026-03.md, etc.
    Include KPI tracking, content performance data, and strategic recommendations.
```

## Naming Conventions

- Use lowercase and hyphens for all file and folder names.
- Include dates in YYYY-MM or YYYY-MM-DD format.
- Include batch numbers where applicable (batch-1, batch-2, etc.).
- Use descriptive names -- someone unfamiliar with the project should understand what a file contains from its name alone.

## Notes

- Never delete client files. If content is revised, keep the original and add a version suffix (e.g., `-v2`, `-v3`).
- The `/brand-guide` folder should always contain the most current Brand Voice Bible. If it's updated, rename the old version with a date suffix.
- Deliverables should be added to the appropriate subfolder as soon as they're drafted, not just when they're approved.
- Feedback files should reference the specific deliverable they relate to.

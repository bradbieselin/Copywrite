# Task Management SOP

> **Purpose:** Standard operating procedure for how CopyDTC tracks, assigns, and completes tasks across all clients and projects. Ensures nothing falls through the cracks.
> **Status:** Scaffold — full content to be built in subsequent prompts
> **Used by:** All CopyDTC team members for daily task management

## Contents

### Task Management System
- Primary tool: Notion / Airtable (choose one)
- Task board structure: Backlog → To Do → In Progress → In Review → Done
- Every task must have: client name, deliverable type, template reference, deadline, assignee, status

### Daily Workflow
- Morning: review task board, identify today's priorities
- Batch similar tasks together (all emails for Client A, then all emails for Client B)
- Update task status as you work (don't batch status updates)
- End of day: review completed tasks, prep tomorrow's queue

### Weekly Rhythm
- Monday: weekly planning — review all client content calendars, set priorities for the week
- Wednesday: mid-week check — are we on track? Any blockers?
- Friday: weekly review — what shipped, what didn't, what carries over

### Priority Framework
- P1 (Today): client deadlines, urgent revisions, launch-day content
- P2 (This Week): scheduled content calendar items, proactive work
- P3 (This Month): internal improvements, template updates, process refinement
- P4 (Someday): nice-to-have projects, experiments

### Client-Specific Views
- Each client should have their own filtered view showing all tasks
- Content calendar integration: tasks auto-generated from content calendar

### Escalation Process
- If a task is blocked → flag immediately, don't wait
- If a deadline is at risk → communicate to client proactively
- If feedback is overdue → follow up at 24 hours and 48 hours

### Capacity Planning
- Track hours per deliverable type to improve estimates
- Flag when approaching capacity limits before accepting new clients
- Maintain a buffer of 20% capacity for revisions and urgent requests
